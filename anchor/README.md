# Anchor ⚓

แอปส่วนตัวสำหรับพัฒนาตัวเองรายวัน พร้อมโหมด "เพื่อนเตือน" สำหรับช่วงที่ความอยากมา

> **ไม่เกี่ยวกับเว็บไซต์บริษัทที่อยู่รากของ repo นี้** — แค่อาศัยอยู่ repo เดียวกันเท่านั้น
> โค้ดทั้งหมดของแอปนี้อยู่ในโฟลเดอร์ `anchor/` และไม่มีไฟล์ที่ build แล้วถูก commit
> ลง repo เลย เว็บบริษัทจึงไม่ได้เสิร์ฟแอปนี้ออกไปไม่ว่าทางใด

เป็น PWA ติดตั้งลงโฮมสกรีนได้ทั้ง iPhone และ Android ใช้งานออฟไลน์ได้
**ข้อมูลทั้งหมดเก็บอยู่ในเครื่องผู้ใช้เท่านั้น** (IndexedDB) ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชี ไม่มีการส่งข้อมูลออก

> แอปนี้เป็นเครื่องมือช่วยประคองตัวเอง ไม่ใช่การรักษาทางการแพทย์
> อาการถอนรุนแรง (มือสั่นมาก ชัก เห็นภาพหลอน) หรือความคิดทำร้ายตัวเอง ให้ติดต่อแพทย์หรือโทร 1669
> สายด่วนยาเสพติด 1165 · สายด่วนสุขภาพจิต 1323

## สิ่งที่มีในเฟส 1

**วันนี้** — เช็กลิสต์รายวันที่เพิ่ม/แก้เองได้ทั้งหมด
- **โหมดพลังงานประจำวัน** (ไหวแค่นิดเดียว / ปกติ / พร้อมอัด) เปลี่ยนจำนวนงานที่ต้องทำเพื่อให้วันนั้นผ่าน — วันที่แย่ก็ยังรักษาสตรีคไว้ได้
- **สลับวิธีทำอัตโนมัติ** งานหนึ่งงานใส่ได้หลายวิธี แล้วแอปหมุนให้คนละแบบทุกวัน (แก้ปัญหาเบื่อรูทีน)
- **ภารกิจสุ่มประจำวัน** หยิบจากเมนูเสริมมาเสนอวันละ 1 อัน
- ตัวนับวันที่ไม่แตะ + เงินที่ประหยัดได้

**เป้าหมาย** — ตั้ง challenge ได้เองว่ากี่วัน (7/14/21/30/66/90 หรือกำหนดเอง)
- เห็นความคืบหน้าเป็น dot grid ทั้งก้อนในหน้าจอเดียว
- **โล่กันสตรีคขาด** เดือนละ 2 ชิ้น — พลาดได้โดยไม่ล้างของสะสม

**เพื่อนเตือน (Guardian)** — ปุ่มที่กดตอนอยากดื่ม/อยากใช้ เข้าโฟลว์ 7 ขั้น
1. หายใจตามวงกลม 60 วินาที
2. เช็ก HALT (หิว / โกรธ / เหงา / ล้า / เบื่อ / อยากฉลอง) พร้อมคำแนะนำตามที่เลือก
3. ให้คะแนนความอยาก 1–10 + ระบุตัวจุด
4. อ่านข้อความที่ตัวเองเขียนไว้ตอนหัวโล่ง + เหตุผลที่เริ่มทำ
5. หน่วงเวลา 5/15/30 นาที (นาฬิกาเดินต่อแม้ปิดแอป) พร้อมรายการทางเลือกที่ตั้งไว้เอง
6. ให้คะแนนอีกครั้งเพื่อเห็นว่าความอยากลดลงจริง
7. บันทึกผลแบบไม่ตัดสิน — รวมถึงกรณีที่พลาดไปแล้ว

ปุ่มขอความช่วยเหลือ (เบอร์คนที่ไว้ใจ + สายด่วน 1165 / 1323 / 1669) อยู่ทุกขั้นตอน และจะเด้งเตือนเองเมื่อให้คะแนนความอยาก ≥ 8

**รางวัล** — แต้มสะสมใช้แลกรางวัลที่ตั้งเอง (บล็อกไม่ให้ตั้งสุรา/สารเป็นรางวัล)
- **การ์ดสุ่ม** โอกาส 28% ทุกครั้งที่ติ๊กงานเสร็จ — โบนัส XP / แต้ม / โล่ / คำเตือนใจ / ปลดล็อกธีม
- เลเวลแยก 5 ด้าน: ใจที่มั่นคง · ร่างกาย · จิตใจ · สมอง · อาชีพ

**ฉัน** — สถิติความอยาก (ผ่านมาได้กี่ครั้ง, ความอยากลดเฉลี่ยเท่าไหร่, ช่วงเวลาที่เสี่ยงที่สุด, ตัวจุดที่เจอบ่อย), ตั้งค่าทั้งหมด, สำรอง/กู้คืนข้อมูลเป็นไฟล์ JSON

## รัน

```bash
cd anchor
npm install
npm run dev        # โหมดพัฒนา — เปิดที่ http://localhost:5173
npm run build      # ได้ผลลัพธ์ที่ anchor/dist (ไม่ถูก commit)
npm run preview    # เปิดตัวที่ build แล้ว
npm run typecheck
```

### ถ้าจะเอาขึ้นมือถือ

`dist/` เป็นไฟล์ static ล้วน เอาไปวางที่ไหนก็ได้ **ยกเว้นอย่าเอาไปวางรวมกับเว็บบริษัท**
เพราะข้อมูลในแอปนี้เป็นเรื่องส่วนตัว ทางเลือกที่แยกขาดจากกัน:

- **ในบ้านตัวเอง** — `npm run dev -- --host` แล้วเปิดจากมือถือผ่าน IP ในวง Wi-Fi เดียวกัน
- **โฮสต์ส่วนตัว** — ลาก `dist/` เข้า Netlify Drop หรือ `vercel deploy` ในโปรเจกต์แยก
  (ตั้งเป็น private / ใส่รหัสผ่านได้)
- **repo แยกต่างหาก** — ย้ายโฟลเดอร์นี้ไป repo ส่วนตัวแบบ private แล้วเปิด GitHub Pages ที่นั่น

ติดตั้งลงโฮมสกรีนเมื่อเปิดเว็บได้แล้ว:
- **iPhone**: เปิดใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android**: เปิดใน Chrome → เมนู → "ติดตั้งแอป"

## โครงสร้าง

```
anchor/src/
  db.ts              schema ของ Dexie/IndexedDB ทั้งหมด + ชนิดข้อมูล
  lib/date.ts        วันที่แบบ local-day string + ฟอร์แมตภาษาไทย
  lib/xp.ts          สูตรเลเวล, XP แยกตามด้าน, การแปลง XP เป็นแต้ม
  lib/rotation.ts    เลือกวิธีทำประจำวัน + ภารกิจสุ่ม (hash ตามวัน)
  lib/cards.ts       ระบบการ์ดสุ่ม (variable reward)
  lib/seed.ts        งานตั้งต้น ทางเลือกตอนอยาก และรางวัลเริ่มต้น
  lib/store.ts       hooks + action ทั้งหมดที่แตะฐานข้อมูล, สูตรคำนวณสตรีค
  screens/           Today · Goals · Rewards · Me · Guardian
  components/        UI kit + ตัวแก้ไขงาน
```

## ที่ยังไม่ได้ทำ (เฟสถัดไป)

- **AI Coach** — วางแผนสัปดาห์, สรุปวันอาทิตย์, ปุ่ม "เบื่อแล้ว" (ช่องใส่ API key มีแล้วในหน้าตั้งค่า)
- **Tracks** — เป้าหมายระยะยาว, ไทม์ไลน์เรียนต่อ ป.โท, คลังคำศัพท์ภาษา
- **Focus & Feed** — นับจำนวนครั้งที่เปิดฟีด, intent gate, คู่มือตั้ง iOS Shortcuts
- Season/ธีมประจำซีซั่น และ boss fight รายสัปดาห์
